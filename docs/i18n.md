# 多语言设计

[English](i18n.en.md)

固件里只有英文。别的语言由两种文件组成，都用 CPS 写进电台：

- **语言文件**（`<代码>.json`）：界面上的文字，一种语言一个文件，几 KB
- **字库文件**（`<名字>.bin`）：固件自带字体里没有的字形，例如中文字库 `cjk.bin`，约 2.6 MB

写进去以后，在“选项 → 语言”里就能选。加一种语言只需要加一个语言文件，不改固件；要用到新文字（韩文、日文……）
时再加一个字库文件。字库和语言分开：同一个中文字库既给中文界面用，也给信道名、联系人名里的汉字用，界面是英文
时也一样。

## 1. 语言文件

UTF-8 的 JSON，翻译的人直接改：

```json
{
  "format": 1,
  "code": "zh",
  "name": "中文",
  "english_name": "Chinese",
  "font": "cjk",
  "strings": {
    "TEXT_LANGUAGE_NAME": "中文",
    "TEXT_MENU": "菜单",
    "TEXT_ZONE": "区域"
  }
}
```

| 字段 | 意思 |
|---|---|
| `format` | 文件格式版本，现在是 1 |
| `code` | 语言代码（ISO 639-1，必要时加地区，如 `pt-BR`），最多 7 个字节；同一代码再写一次就是替换 |
| `name` | 用这种语言自己的文字写的名字，菜单里显示它 |
| `english_name` | 英文名，CPS 里显示；字库没装时电台菜单也显示它 |
| `font` | 需要的字库名；只用固件自带字形（ASCII、Latin-1）的语言不写 |
| `strings` | 文字：键是 `src/ui/text/text.h` 里的 `TEXT_x` 名字 |

- **英文是基准**：`tools/text/languages/en.json` 有全部键，`tools/text/gen_text.py` 用它生成 `text.h`、
  `text_en.c` 和键表（第 3 节）。英文编进固件，是默认语言，也是别的语言缺条目时的替补。
- 缺的条目显示英文；不认识的键（老固件里删掉的）忽略。所以新旧固件和语言文件可以混用。
- 格式符（`%d`、`%s`……）必须和英文的一样多、一样顺序。CPS 写入前检查，固件读入时再查一次，不一致的那条改用
  英文，坏文件不会让电台出错。
- `tools/text/check_lang.py <代码>.json` 给翻译的人用：列出缺的条目、格式符不对的、按固件字体量出来超宽的。
- 现有的中文、西班牙文转成 `zh.json`、`es.json`，随固件一起发布（GitHub Release 和 `dist/languages/`）。

## 2. 字库文件

固件里的 Roboto 有 ASCII 和 Latin-1（西、法、德、葡等的带音调字母），9 个字号，这些语言不用字库。其余的文字
放在字库文件里：

| 字库 | 内容 | 大小 |
|---|---|---|
| `cjk` | GB2312 全部（17 px），一级字（32 px 粗体），GB2312 → Unicode 对照表（码表里的名字） | 2.63 MB |
| 韩文（以后） | 常用 2350 个音节，17 px | 约 330 KB |
| 日文（以后） | 日本独有的汉字约 1000 个，17 px（假名在 `cjk` 里） | 约 140 KB |

`tools/fonts/mkfont_pack.py`（由 `mkcjk.py` 改成）生成。文件格式，小端：

```
0   "DM32FNT1"
8   u32 文件长度
12  u32 CRC-32（第 64 字节起）
16  char 名字[8]（ASCII，0 补齐，如 "cjk"）
24  char 语言[8]（可选：这套字形是给哪种语言的，如日文汉字写 "ja"）
32  u8 字体数，3 字节空
36  u32 GB2312 对照表偏移（0：没有）
40  u32 字体表偏移
44  保留到 64
字体表：每套 { u32 偏移, u16 字数, u8 像素大小, u8 粗体 }，个数不限
每套字体、字形的压缩格式和现在的 cjk.bin 一样（mkcjk.py 的说明）
```

## 3. 文字的编号

语言文件按名字写，电台里按编号找。为了让 CPS 不用知道固件的编号，新旧版本也能混用：

- 每个键的名字算 FNV-1a 32 位哈希，Flash 里存哈希和文字
- `gen_text.py` 生成按哈希排好序的 `{哈希, 编号}` 表编进固件（约 2.6 KB），并检查没有两个键哈希相同
- 固件读语言时逐条查表，得到这条文字的编号；查不到的跳过
- 这样 `TEXT_x` 的编号可以随固件变，CPS 只要会算哈希

## 4. 外部 Flash 的布局

原来的中文字库区（0x280000–0x630000，3.69 MB）分成两块：

| 地址 | 内容 |
|---|---|
| 0x280000–0x2A0000 | 语言区：8 个槽，每个 16 KB |
| 0x2A0000–0x2A1000 | 字库目录 |
| 0x2A1000–0x630000 | 字库（3.55 MB：中文 2.63 MB，还剩约 0.9 MB） |

**语言槽**（16 KB，自带头，没有目录）：

```
0   "DM32LANG"
8   u32 长度
12  u32 CRC-32（第 16 字节起）
16  char 代码[8]
24  char 名字[32]（UTF-8，用自己的文字）
56  char 英文名[24]
80  char 字库名[8]
88  u16 条数，2 字节空
92  条数 x { u32 哈希, u16 文字偏移（从槽开头算） }
    然后是文字，UTF-8，以 0 结尾
```

CPS 先写槽的其余部分，最后写头所在的第一页；写到一半断电，这个槽没有合法的头，不会被用。删除就是擦掉第一个扇区。

**字库目录**（一个扇区）：

```
0   "DM32FDIR"
8   u8 个数，3 字节空
12  最多 16 x { char 名字[8], u32 地址, u32 长度, u32 CRC-32 }
```

CPS 在空地方写字库，写完再改目录。删除只改目录。

## 5. 固件

- 只编进英文（`text_en.c`）；删掉 `text_zh.c`、`text_es.c`
- 选中一种语言时（开机和在菜单里选），把整个槽（16 KB）读进内存，加每条一个 u16 偏移。格式符逐条和英文比。
  `text()` 照旧返回 `const char *`，用它的地方都不用改
- 语言存的是代码，不再是编号：码表自定义数据块 “DT” 8（0x44540008：版本 1、3 字节空、`char 代码[8]`）。
  开机时找不到那个语言，就用英文
- 兼容：没有 “DT” 8 块时读 “DT” 4（编号：1 中文、2 西班牙文），也没有时 `bitfield_options` 第 19 位为 1 就找 `zh`。
  选 `zh` 时照旧置第 19 位，“DT” 4 在的话也跟着改
- 语言菜单：English 加上装了的语言，每种用自己的名字；它要的字库没装时显示英文名，界面文字显示成“??”，提醒字库没装
- 字形：先找固件里的 Roboto，再找当前语言要的字库，再找别的字库（目录的顺序）。中文和日文共用汉字码位，所以
  当前语言的字库优先，日文界面里的汉字用日文字形
- GB2312 名字：用第一个带对照表的字库
- 字体数不再限 4 套（`font_cjk.c` 改成字库目录 + 多个字库）

## 6. CPS

- 发布包里有 `languages` 文件夹：`zh.json`、`es.json` 和 `cjk.bin`（中文要用），是原始文件。CPS 的“界面语言”页里
  选择这个文件夹（双击打开的网页不能自己读旁边的文件），中文和西班牙文默认勾选，用户只要点“写入”；不要的可以取消勾选
- 字库按名字对应：语言文件的 `font` 是字库文件头里的名字。勾选的语言要用的字库，电台里没有也没选到时，页面上和写入前都会提醒
- 新页面“语言”：列出电台里的语言（代码、名字、条数、缺几条）和字库（名字、大小），显示剩余空间
- **加语言**：选一个 `.json`。检查格式、格式符、长度（一个槽 16 KB）；它要的字库没装时提示，并可以一起选字库文件
- **加字库**：选一个 `.bin`，检查头和 CRC，找空地方写入，改目录
- **删除**语言或字库；删掉当前语言时电台回到英文
- 写入：`'X'` 命令的扇区号最高位（0x800000）为 1 时，表示外部 Flash 的原始地址，固件只允许写
  0x280000–0x630000。还用现有的分块写和 CRC 回读（`writeVerifiedSector`、`sectorCrc`）
- 写完让电台重新读语言区和字库目录，不用重启
- 不再需要 `tools/fonts/upload_cjk.py` 和调试命令 `'D' 'F'`

## 7. 升级

原来的 `cjk.bin`（`DM32CJK2`）不再识别。从老版本升上来的中文用户，要用 CPS 写一次 `cjk.bin` 和 `zh.json`；没写
之前界面是英文，中文名显示不出来。发布说明里要写清楚。

## 8. 码表里的名字

信道、区域、联系人的名字是 GB2312，16 字节。中文、英文、日文假名都够用，暂时不动。韩文名字等以后换编码（比如
码表整体标记为 UTF-8，由 CPS 转换）才支持；UTF-8 下 16 字节只能放 5 个韩文或汉字，这个限制要在界面和 CPS 里说明。

## 9. 从右往左的文字

阿拉伯文、希伯来文从右往左写，阿拉伯字母还要按在词里的位置变形。现在不做，但不要堵死：所有文字都经过同一个
绘字函数（`font_draw_text()`），以后在那里加双向排序和变形；界面左右镜像是另一步。

## 10. 分步

| 步 | 内容 |
|---|---|
| 1 | 工具：`en.json` 为基准，`zh.json`、`es.json`；`gen_text.py` 生成键表；`check_lang.py`；`mkfont_pack.py` |
| 2 | 固件：语言区、字库目录和多字库、语言存代码、菜单、`'X'` 原始地址写入；只编英文 |
| 3 | CPS：语言页面，写入和删除语言、字库 |
| 4 | 在电台上试：英文 → 写中文 → 西班牙文 → 删除 → 断电重写；删掉 `upload_cjk.py`、`'D' 'F'` |

## 怎么帮忙

- **翻译**：复制 `en.json`，改 `code`、`name`、`english_name` 和文字，运行 `py tools/text/check_lang.py`，
  改掉它报的问题，用 CPS 写进电台，每个界面看一遍，开 PR 到 `develop`（文件放 `tools/text/languages/`）
- **写代码**：开工前在 issue 里说一声，免得重复
- PR 的说明里写清楚在电台上看过哪些界面
