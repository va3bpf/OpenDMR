# FD6818 寄存器要点

FD6818 和 Beken **BK4819**（泉盛 UV-K5 用的芯片）寄存器兼容（2026-11-04 核对）：本机读出的 0x71 = 0x8517、0x72 = 0x2854、
0x44 = 0x9009、0x45 = 0x31A9、0x74 / 0x75 = 0xF50B 都是 BK4819 的复位默认值；0x30 发射 0xC1FE / 接收 0xBFF1、0x37 = 0x1D0F、
0x10 ~ 0x14 的 AGC 表也都是 BK4819 的典型值。所以寄存器含义以 BK4819 的官方手册为准。

资料（不放进仓库）：

- Beken《BK4819 Registers V1.1》（REG-BK4819-E02）：https://github.com/egzumer/uv-k5-firmware-custom/files/13532694/BK4819.Registers_V1.1.pdf
- RadioFoundry，Radioddity DB25-D 硬件说明（4.4 节 BK4819、4.8 节 FD6818 的发音调序列）：https://radiofoundry.org/docs/spec/hardware-db25d
- UV-K5 开源固件（egzumer/uv-k5-firmware-custom）里的 BK4819 驱动可作写法参考。

晶振按 13/26 MHz 计（亚音系数 20.64888 与本固件 `CTCSS_SCALE` 一致）。

## 和声音有关的寄存器

| 寄存器 | 位 | 含义 |
|---|---|---|
| 0x30 | 9 | 音频 DAC 使能（发射时要本机出提示音需置 1：0xC1FE → 0xC3FE，原厂发音调用 0xC3FA） |
| 0x47 | 11:8 | 音频输出选择：0 静音，1 正常音频，2 接收时输出 Tone1，3 发射时输出提示音（先开 Tone1，并置 0x30 bit 9），6 亚音（测试），8 FSK（测试） |
| 0x47 | 13 | 解调后增益 +6 dB |
| 0x48 | 11:10 / 9:4 / 3:0 | 接收音频 Gain1（0 ~ -18 dB）/ Gain2（-26 ~ +5.5 dB）/ DAC 增益（约 2 dB 一档）；本固件写 0x31E0 \| 校准音量 |
| 0x50 | 15 | 发射话筒静音（"用于发 DTMF 等"）。0x3B20 正常，0xBB20 / 0xBB18 静音——旧工程"BB20 偏移太小"就是话筒被静音了 |
| 0x51 / 0x52 | — | CTCSS / CDCSS 发射、尾音（120° / 180° / 240° 相移或 134.4 Hz） |
| 0x58 ~ 0x5F | — | FSK 收发（原厂 0x3065330、0x3065b38 在用） |
| 0x70 | 15 / 14:8 | Tone1 使能 / 增益 |
| 0x70 | 7 / 6:0 | Tone2 使能 / 增益（也是 FSK 增益） |
| 0x71 | 15:0 | Tone1 频率字 = Hz × 10.32444 |
| 0x72 | 15:0 | Tone2 / FSK 频率字 = Hz × 10.32444 |
| 0x52 | 15 / 14:13 | 尾音：bit 15 开，14:13 = 0 134.4 Hz（DCS）、1 120°、2 180°、3 240° 相移；平时 0x028F |

## 原厂和别家的用法

- 原厂发数据 / 音调（0x3065a88）：0x50 = 0xBB18（话筒静音）、0x30 = 0xC3FA 发射，结束后 0x50 = 0x3B18。
- RadioFoundry 记录的 FD6818 发音调：写 0x71、0x70，0x30 = 0xC3FA，0x47 = 0x7840；停止 0x70 = 0、0x47 = 0x7040。
  （那台机 0x47 的高位和本机不同，本机用 0x6042 / 0x6142，只改 bit 11:8。）
- 原厂 FM 语音发射：0x50 = 0x3B18，FD6818 用自己的话筒通路，基带不开 FM_PTT（见 architecture.md 第 7 节）。
- 原厂尾音（0x300E84C，和 UV-K5 固件的 BK4819_GenTail() 一样，按参数）：0x07 = 0x046F（亚音发生器改 55 Hz），或 0x52 =
  0x828F / 0xA28F / 0xC28F / 0xE28F。发射结束时（0x300DD44）按设置用 240° 相移（0xE28F）或 55 Hz，再等 300 ms 停发射。

## 本固件的用法

- 按键音、以后的语音提示：走 HR_C7000 基带的提示音通道（OpenGD77 的做法），放音时把音频开关 0x2F 拉低。
- FM 发射开始 / 结束的空中提示音、发射时按 SK2 的 1750 Hz、按数字键的 DTMF：Tone1（DTMF 加 Tone2），0x30 = 0xC3FA
  （话筒 ADC 关、AF DAC 开，同原厂发音调），完了 0x70 = 0、0x30 = 0xC1FE。增益 = 空中音电平 × 12（UV-K5 固件用 66）。
- 本机的发射开始 / 结束音、1750 / DTMF 的本机监听：走基带提示音通道，和按键音一样。
- 尾音消除：照原厂，DCS 发 134.4 Hz（0x828F），CTCSS 按设置 240° 相移或 55 Hz，300 ms 后停发射，再写回 0x52 = 0x028F。
  接收端检测尾音还没做。
- MDC1200 PTT ID（`services/mdc1200` 组包，`fd6818_tx_fsk()` 发送）：照 UV-K5 固件（OneOfEleven）的 BK4819_send_MDC1200()，
  0x58 = 0x3C03（FFSK 1200/1800），0x72 = 1200 Hz、0x70 = 0x0080 | 96，0x2B = 0x0005（关预加重和 300 Hz 高通），
  0x40 频偏 850（窄）/ 1050（宽），0x51 暂时关亚音，0x59 前导 4 字节、同步 4 字节（同步字节 0，MDC 的同步在数据里），
  0x5C = 0x5625（不加 CRC），数据 16 位一写进 0x5F，0x3F 开发送完中断，查 0x0C bit 0 / 0x02 bit 15 等发完。
  单位 ID 用 DMR ID 的后 4 位十进制数字（1234 即 0x1234）。
